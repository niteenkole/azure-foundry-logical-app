Put a trusted backend behind the screen.

The backend is the application boundary. It receives the question, owns the credential, and becomes the only component allowed to call Azure AI Foundry.

Security decision: the browser never receives the model endpoint secret. The backend owns configuration and controls the outbound call.

Live steps

  1. Create a virtual environment and install fastapi, uvicorn, and the Azure client.
  2. Create backend/main.py with POST /ask.
  3. Run uvicorn backend.main:app --reload and test one question.
CODE BOARDbackend/main.py
from fastapi import FastAPI
from os import environ

app = FastAPI()

@app.post("/ask")
async def ask(request: Question):
    # credential stays on the server
    response = foundry_client.complete(
        request.question
    )
    return {"answer": response.text}
