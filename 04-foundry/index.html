Live steps

  1. Create the Azure AI Foundry project and model deployment.
  2. Set AZURE_ENDPOINT, AZURE_API_KEY, and MODEL_DEPLOYMENT locally.
  3. Make one real backend request and show the response in the terminal.
CODE BOARDfoundry/client.py
from openai import AzureOpenAI

client = AzureOpenAI(
    azure_endpoint=environ["AZURE_ENDPOINT"],
    api_key=environ["AZURE_API_KEY"],
    api_version="2024-10-21",
)

response = client.chat.completions.create(
    model=environ["MODEL_DEPLOYMENT"],
    messages=messages,
)
