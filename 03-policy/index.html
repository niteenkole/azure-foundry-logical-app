Live Azure steps

  1. Open the Azure AI Foundry project and create or open the assistant/agent.
  2. Write instructions to answer from approved sources, cite them, and say when the source is silent.
  3. Attach the Foundry knowledge source and test grounded and out-of-scope questions.
  4. Update instructions in Foundry when behavior changes; do not edit a local Python prompt.

def validate_question(question):
    normalized = question.strip()
    if not normalized:
        raise ValueError("Question required")
    if len(normalized) > 2000:
        raise ValueError("Question too long")
    return normalized
